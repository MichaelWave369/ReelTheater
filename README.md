# REEL Theater

A local-first, controller-friendly home theater and arcade experience for the living room. Built to complement [ReelCommons](https://github.com/MichaelWave369/ReelCommons), not replace it.

The first implementation is an Xbox Series X Microsoft Edge prototype. Playback and controller behavior require real-device validation.

See the initial implementation pull request for the actual runnable application and setup instructions.
